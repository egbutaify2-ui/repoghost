04 / BEHIND THE VEIL

Something remains.
Question everything.

The ghost is a guide through public records, not an oracle. Here is what happens behind the veil.

A

Listen for the echoes

RepoGhost follows public profile and repository records: README files, commits, open issues, and releases when available. These are the footprints left behind. Missing or sampled evidence is called out rather than filled in with fiction.

GITHUB REST API / PUBLIC RECORD
B

Ask what the machine remembers

An open-weight model helps interpret the collected evidence and answer supported questions. Source references are validated against the record, while repository text is treated as untrusted input. No invented source. No supernatural certainty.

OPEN-WEIGHT AI / SOURCE CHECKS
C

Leave with a next move

The ghost leaves you source-linked findings, potential risks, and practical next steps. It never pushes code, opens issues, forks projects, or executes repository code. You decide what deserves to be brought back to life.
